Admin permissions

The Admin role is never granted from this page or from browser data. The dev server verifies the admin email and password against its own configuration (ADMIN_EMAIL + a hashed password from tools/init_admin.py) and issues a 12-hour admin session it checks on every page load. To change who is admin, re-run that script and restart the server (see README → “Admin setup”).
